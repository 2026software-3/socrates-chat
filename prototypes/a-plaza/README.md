# Prototype A：追問廣場

入口提案 A 的可操作版本，對應 Figma section「提案 A · 追問廣場（完整流程）」與 Design 畫布 A 頁。單一 HTML 檔，直接用瀏覽器打開即可（需連網載入 CDN 上的 GSAP 與 Google Fonts）。

涵蓋：

- 入口：標題、對話舞台（三輪「說 → 追問 → 打磨」，粗糙多邊形變成圓）、拱門登入卡、身分說明。
- 登入卡狀態：欄位驗證、登入中、帳密錯誤（不透露哪一個錯）、逾時被登出。
- Google 登入（帳號選擇為示意畫面）、名單外帳號的「尚未開通」與重新檢查。
- 穿門轉場：登入成功後拱門從燈的位置放大，帶進依身分的首頁（學生、教師、系統管理者）。
- 運作方式頁、「給教師」會標出第三步；入口文案可切換中文與英文。

示意帳號：student@demo.tw、teacher@demo.tw、admin@demo.tw、outsider@demo.tw（名單外），密碼任意非空；其他信箱會顯示帳密錯誤。

支援 `prefers-reduced-motion`（不播舞台與穿門，直接呈現終態與切換頁面）、分頁隱藏或舞台離開視窗時暫停動畫、手機版（舞台縮成一輪對話、登入卡改為淺拱形）。
