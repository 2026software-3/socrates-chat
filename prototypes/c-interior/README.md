# 系統內頁原型：地圖與刻字

登入後的內頁殼層，給前端實作時參考版面與動畫。規範見 [DESIGN.md](../../DESIGN.md) 的「導覽決策」與「Toast」，設計稿在 Figma [00] Guideline 02、03。

## 設計內容

- **情境**：
  - 工作情境是 Topbar＋側欄＋白色內容區＋頁尾。
  - 專注情境（對話頁）只有返回列，沒有側欄與頁尾。
- **Topbar**：
  - 左邊是品牌「蘇格拉底・教室 Schola Socratica」。
  - 中間是目前位置：編號圖釘＋拉丁建築名＋中文區名。
  - 右邊是學生點數、頭像與名字，點了打開帳號選單，可以登出回到入口。
- **側欄**：上方是廣場平面圖（仿 Nolli 1748 年羅馬地圖），每個區域是一棟建築，所在那棟打開成白色並標上編號；下方是圖例。
- **色彩**：紙與墨為主，狀態標籤、點數、蘇格拉底的發言、論點分布與送出鍵用 DESIGN.md 的顏料（銅綠、赭金、龐貝藍、硃砂）。
- **頁首**：該建築的版畫切片（`assets/plate-1..4.jpg`，從入口的四個站點輸出），向左淡出成白色，左側是標題與拉丁名。
- **動畫**：只在「抵達」時播放，開啟「減少動態」時直接顯示結果。換頁時依序：
  1. 平面圖上的建築打開。
  2. Topbar 的拉丁名逐字刻出（每字從上往下露出，字距間隔 40ms）。
  3. 頁首的拉丁名再刻一次。
- **寬度**：
  - ≥ 1024：側欄常駐。
  - 768–1023：☰＋抽屜。
  - < 768：底部分頁列（依編號排序的 3 個常用區域＋「廣場」）＋平面圖面板。點「廣場」或 Topbar 的位置銘文打開面板；往下拖、點遮罩或按 Esc 都會關閉。

## 檔案

- `index.html`：頁面、Topbar、側欄、平面圖、手機分頁列與面板。
- `shared.css`：色彩、字體、控制項與版面。
- `shared.js`：示意資料、路由（網址 hash）、帳號選單、對話送出。
- `ISSUES.md`：可以拿去開 GitHub Issue 的規格與前端任務草稿。

## 怎麼看

用本機伺服器開（見 [prototypes/README.md](../README.md)），網址後面加 `#t-classes` 看教師頁、`#talk` 看對話頁、`#points` 看點數。把視窗縮到 768 以下，可以看手機版的底部分頁列。左下角的黑色小工具列只是原型用來切換身分，不屬於設計。

Toast 通知只畫在 Figma，這個原型沒有做。
