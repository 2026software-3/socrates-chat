## 1. [S-xx] 產品內頁的情境、導覽與殼層（方案 D）

**類型**：Spec（labels：frontend）

### 決策主題
把 2026-11-10 定案的方案 D 寫進 `docs/specs/decisions.md`，作為前端實作與 F-21（響應式介面）的依據。

### 需決定（已有提案，待需求方在 PR 中核准）
- **三種情境**：入口、工作情境、專注情境。工作情境是 Topbar＋側欄＋白色內容區，專注情境是返回列，沒有側欄。
- **斷點**：≥ 1024 側欄常駐（216）；768–1023 改成 ☰＋同一個 216 抽屜；< 768 改成底部分頁列＋平面圖面板（2026-11-18 定案）。程式目前以 768 切換，要改。
- **區域與建築對照**：三種角色的全域區域與羅馬數字見 DESIGN.md。
  - 管理者 IV 是「共用書庫」（Aedes Satvrni，與教師同一棟），修課名單改為教室管理裡的頁籤（2026-11-21）。
  - 待確認：管理者的「執行日誌」沒有獨立畫面。
- **頁首**：區域首頁用版畫切片（Page/Header），子頁用 Page/Title（標題＋同一行拉丁名）。
- **頁尾**：只在工作情境，拉滿內容區。
- **手機 Topbar**：不顯示點數，沒有 ☰；位置銘文旁有 ⌄，點了打開平面圖面板。
- **通知**：操作結果用 Toast，頁面狀態用頁內 Alert，需要決定的事用對話框。

### Given / When / Then
- Given 學生在 1440 寬，When 進入任一區域，Then 看到 Topbar（品牌｜目前位置｜點數、頭像）、側欄（平面圖＋圖例，所在區域標成目前）、白色內容區與頁尾。
- Given 寬度 768–1023，When 點 ☰，Then 216 側欄從左側滑出蓋住內容，點遮罩或按 Esc 關閉，焦點回到 ☰。
- Given 寬度 < 768，When 進入任一工作情境的區域，Then 底部固定分頁列，依編號排序的 3 個常用區域＋「廣場」；When 點「廣場」或位置銘文，Then 平面圖面板從底部升起。
- Given 學生在對話頁，When 看頂端，Then 只有返回列（返回、標題、所在建築與輪數），沒有側欄與頁尾。
- Given 管理者，When 看側欄，Then 有 7 個區域；「執行日誌」在規格確認前標為待確認。

## 2. [F-xx] 產品內頁殼層（方案 D）

**類型**：Feature（父 Issue，不加 label）。依 1 完成後開始。

**使用者情境**：身為學生、教師或管理者，我想隨時知道自己在系統的哪一區、能去哪裡，以便不迷路地完成工作。

### 2.1 [F-xx.1-FE] Topbar：品牌、目前位置、點數與帳號選單
**Labels**：frontend
- Given ≥ 1024，Then 左側是「蘇格拉底・教室」＋「Schola Socratica」；中央是編號圖釘＋拉丁建築名（字詞以 · 分隔）＋中文區名；右側是點數（只有學生）＋頭像＋名字。
- Given 768–1023，Then 拉丁副標與中文區名收起，出現 ☰。
- Given < 768，Then 只留拉丁建築名（旁邊有 ⌄，點了打開平面圖面板）與頭像，沒有 ☰。
- Given 點頭像與名字，Then 在頂列下方靠右打開帳號選單（姓名、角色、語言、登出），點外面或按 Esc 關閉；登出回到入口。
- 數字用 Noto Serif TC，不用 IM Fell（IM Fell 的 1 會被讀成羅馬數字 I）。
- **權限與失敗情境**：名單外帳號看不到內頁（入口顯示「尚未開通」）；點數 API 失敗時隱藏點數，不顯示 0。

### 2.2 [F-xx.2-FE] 側欄：廣場平面圖與圖例
**Labels**：frontend
- Given 角色與目前區域，Then 平面圖上該建築由黑色打開成白色內部與柱子並標上編號，圖例同一列標成目前（紅粉筆字、左側 2px 記號），並設 `aria-current="page"`。
- Given 滑鼠移到圖例或建築上，Then 兩者一起標示。
- Given 鍵盤操作，Then 平面圖設 `aria-hidden`，只有圖例可以聚焦；每列至少 44px 高。
- Given 768–1023，Then 同一個面板放進抽屜（見 1 的 Given/When/Then）。

### 2.2b [F-xx.2b-FE] 手機的底部分頁列與平面圖面板
**Labels**：frontend
- Given < 768 的工作情境，Then 底部固定分頁列（63 高，上緣雙墨線）：學生 I、II、III，教師 I、II、V，管理者 I、II、III，最後一格是「廣場」；目前那格紅粉筆字＋上緣 2px 記號並設 `aria-current="page"`。
- Given 目前區域不在前 3 格，Then「廣場」那格標成目前，文字改成編號與區名（例如「IV・點數」）。
- Given 點「廣場」或 Topbar 位置銘文，Then 平面圖面板從底部升起（`role="dialog"`、`aria-modal`），內容是放大的平面圖與兩欄圖例；點區域換頁並收起，建築打開的動態照 2.5。
- Given 面板開著，When 往下拖超過 90px、點遮罩、按 Esc 或 ✕，Then 關閉並把焦點還給原本的按鈕。
- Given 專注情境，Then 不顯示分頁列；工作情境的內容區底部多留 64。
- 原型：`c-interior/index.html` 寬度 < 768。

### 2.3 [F-xx.3-FE] 頁首、子頁標題與頁尾
**Labels**：frontend
- 區域首頁的 Page/Header：
  - 版畫滿版（cover），依建築選版畫並對準位置，與原型 `PLATE`、`POS` 相同：
    - Basilica Ivlia：plate-1、58% 62%。Aedes Vestae：plate-1、92% 58%。Aedes Castoris：plate-1、78% 45%。
    - Rostra：plate-2、50% 55%。Tabvlarivm：plate-3、50% 40%。
    - Aedes Satvrni：plate-4、40% 40%。Cvria：plate-4、55% 30%。
  - 顏料淡彩疊在版畫上（multiply、35%）：Basilica＝`aerugo`，Aedes Satvrni＝`ochra-graphic`，Rostra＝`caeruleum`，其他不疊。
  - 最上面是白色漸層：桌面 96% → 72%（34%）→ 0（64%）；< 768 改成 95% → 80%（60%）→ 30%（100%）。
  - 左側是標題、拉丁名、說明，右上角是編號圖釘。
  - 手機高 150、不顯示說明。
- 子頁的 Page/Title：標題同一行接拉丁名。
- 頁尾：紙色帶，上方雙線，拉滿內容區，左為 SCHOLA SOCRATICA · 年份＋品牌，右為使用說明、紀錄與隱私、語言。內距桌面 40、手機 16。

### 2.4 [F-xx.4-FE] 專注情境的返回列
**Labels**：frontend
- 返回、標題（單行截斷），可開搜尋，右側是所在建築與細節（例如「講壇・第 5 輪」）。
- 手機收起「返回」字樣與銘文。
- 從其他頁進來時，返回要回到上層（例如我的對話），不要依賴瀏覽器的上一頁。

### 2.5 [F-xx.5-FE] 動態：打開建築、刻出名字
**Labels**：frontend
- Given 換區，Then 依序：
  1. 平面圖的建築打開：填色 0.35 秒，紅粉筆描邊 0.7 秒。
  2. Topbar 的拉丁名逐字刻出：每字 0.5 秒，字距間隔 40ms。
  3. 0.38 秒後，頁首的拉丁名再刻一次。
- Given 同一頁更新（例如對話輪數），Then 不重刻。
- Given `prefers-reduced-motion: reduce`，Then 直接顯示結果。
- 原型用 CSS `clip-path` 與 `animation-delay` 做刻字，也可以改用已採用的 GSAP（2026-11-20）。

### 2.6 [F-xx.6-FE] 入口登入後的轉場
**Labels**：frontend
- Given 在入口登入成功，Then 墨水淹沒畫面後進入該角色的區域首頁：學生到我的教室，教師與管理者到教室管理或總覽。
- Given 減少動態，Then 直接切換。
- 原型：`b-roman-forum/vedute.html` 在本機會轉到 `c-interior/index.html`。
- **相依**：Three.js 與 GSAP 已採用（2026-11-20，見 `docs/specs/decisions.md` S-11）；無 WebGL 時的替代畫面仍待決定。

### 2.7 [F-xx.7-FE] Toast 通知
**Labels**：frontend
- Given 使用者完成儲存、複製、加入、移除等操作，Then 顯示 Toast，不插進內容、不推動版面。
- Given Success 或 Info，Then 4 秒後消失；滑鼠移上去或鍵盤聚焦時暫停。Given Error，Then 留到使用者關閉，可帶「重試」。
- 一次只顯示一則，新的取代舊的。`role="status"`（Error 用 `role="alert"`）。
- 位置：≥ 768 在內容區右下（距邊 24，寬 360）；< 768 在底部分頁列上方 12，左右 16；專注情境在輸入框上方。
- 頁面狀態（載入失敗、無權限、唯讀）維持頁內 Alert；刪除確認、臨時密碼、購買成功維持對話框。
- 依 AGENTS.md 不新增 toast 套件，先確認 shadcn/ui 現有的 toast 元件能否套上這個外觀；需要新依賴時先開規格討論。

### 先行測試（每張 FE 任務）
- [ ] 元件測試：三種寬度的 Topbar 與側欄狀態、`aria-current`、抽屜的焦點管理。
- [ ] 帳號選單：開、關、Esc、登出。
- [ ] 減少動態時不播動畫。
- [ ] 手機：分頁列的 `aria-current`、平面圖面板的開關與焦點歸還。
- [ ] Toast：自動消失、懸停暫停、Error 不自動消失、不改變內容區高度。
