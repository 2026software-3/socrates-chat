# S-06.3 書目來源與閱讀推薦規格（草案）

> 對應 [#130](https://github.com/2026software-3/socrates-chat/issues/130)。外部來源尚未選定，Issue 保持開啟，不解除功能實作阻擋。摘要見 [decisions.md](decisions.md)，待決事項見 [open-decisions.md](open-decisions.md#s-063-外部書目資料庫130)。

## 1. 範圍

涵蓋 F-14.1 推薦與書目查核、F-14.2 呈現與無結果、F-14.3 教師書單管理，外部資料流亦影響 F-23.1。沿用 S-06.4 來源與逾時規則、S-02 個資與權限、S-12.1 三語、S-14 全域書單與封存／刪除規則。

活動依 S-04.7 支援多題目，每位學生每題至多一場對話；已有對話後只能新增題目，不能移除、更換或重排已有對話的題目（[PR #381](https://github.com/2026software-3/socrates-chat/pull/381)）。

不包含產品程式碼、migration、實際匯入、API 路徑／schema、模型選型、跨場偏好建模、閱讀追蹤與獎勵、購借書整合、整個外部書庫匯入及教師端 CSV 上傳介面。

**後續方向**：未來可考慮加入短文或文章推薦，來源與推薦規則另行討論。

## 2. 學習目的與適用對象

- 對象為大學生，哲學背景未知；用清楚易懂的語言引導反思，不推斷閱讀能力、不預設熟悉術語，也不排除原典或進階書籍。
- 只依單場討論，幫助學生理解自己的想法、理由與疑問；不代答、不判定固定思想流派。
- 相近或不同立場皆可，不設立場配額；相關性優先，不牽強分類，也不僅憑書名宣稱難易程度。

## 3. 推薦時機與輸入

1. 主動或達上限結束對話，且 AI 總結成功後自動推薦；活動每題各自處理，不等待其他題目。總結未成功時沿用其重試流程。
2. 先顯示總結，推薦另有載入、成功、無結果及失敗狀態，不阻擋完成對話流程。
3. 不設回合數或明確立場門檻；討論少時可依題目推薦，不臆測學生立場，允許無結果。
4. 輸入為該場題目、逐則對話與既有總結，區分學生表達與 AI 假設。觀點變化從對話分析，不修改總結格式；超長時只用既有總結與題目，不額外摘要或推測未記錄的轉折。
5. 重試重新讀取既有資料。只保存最終推薦及必要流程狀態，不複製對話／總結，也不另存觀點摘要、評分或淘汰理由。
6. 後端送往 AI 前依 S-02.6 遮蔽個資，不附帳號身分；原文、總結與個人化分析／推薦不得寫入日誌。

## 4. 共用書庫與書單

### 4.1 書單關係

| 對象 | 用途與關係 |
| --- | --- |
| 共用書庫 | 全體教師共用，收錄團隊初始匯入及教師新增書目；啟用書目可跨題目推薦 |
| 題目預設書單 | 從共用書庫選取，供個人練習使用；沿用題目編輯權限 |
| 活動內各題書單 | 加入題目時複製其預設書單；各自增減、不再同步、不影響其他題目或活動；沿用活動管理權限 |

- 移除書單項目只刪關聯，不刪書目、不禁止推薦。推薦開始時讀最新適用書單；僅該書單中的書取得「教師推薦」標示，其他題目或共用書庫中的書不因此取得標示。
- 活動無對話時更換題目，須告知並確認取代該題書單，取消不改；其他題書單不變。已有對話時依 S-04.7 只能新增題目，新題同樣複製預設書單。

### 4.2 書目權限與狀態

- 教師可新增、修改自己新增的書目；管理者可修改全部書目及初始匯入資料。停用、重新啟用、永久刪除僅限管理者。
- 停用保留資料及書單關聯，教師整理書單時顯示「已停用」；不能加入新書單，新推薦與參考書單均排除。
- 永久刪除不可復原；顯示書名及影響，管理者再次確認才刪除書目與所有書單關聯，取消不改。書目修改、停用或刪除均不改寫已保存推薦。
- 保存推薦前排除已刪書目；保留其餘有效結果，不追加 AI 呼叫。全部移除則視為失敗，可手動重試。

## 5. 教師建立書目與初始匯入

### 5.1 教師搜尋與手動新增

- 所有教師可新增至全域書庫。以書名、作者或 ISBN 經 Rust 後端搜尋外部 API；搜尋不直接寫入，選定書與版本、確認或修正預填資料後才匯入，並可加入正在編輯的書單。
- 手動新增只必填書名；作者、語言、出版年、ISBN、來源連結、簡介及推薦說明皆選填。教師提供的書目只做欄位／格式驗證，不以外部查得到為收錄門檻。
- 用書名搜尋補缺值；多個候選供教師選擇，查無結果或來源缺欄位時留白，不由 LLM 猜補。
- API 故障／逾時保留原填內容，仍可手動建立；顯示「外部服務暫時無法使用，尚未補資料」，不當作查無結果、不反覆自動重試。

### 5.2 團隊初始書單

- 團隊整理 CSV，由開發團隊以指令匯入，只建立共用書目，不綁題目／活動或自動標「教師推薦」；不做批次上傳介面。
- CSV 為 UTF-8，接受 BOM，第一列為欄位名稱；每列一本，只必填 `title`。選填欄位為 `authors`、`isbn`、`language`、`publication_year`、`source_url`、`description`。指令須附範例檔：
  ```csv
  title,authors,isbn,language,publication_year,source_url,description
  示範書名,,,,,,
  ```
- 同樣以書名補缺值，查不到留白。多個候選或 API 故障／逾時，保留原填內容建立有效非重複書目，報告行號、書名及原因，標為「已匯入但待補資料」，不計為失敗；不自動選版本或反覆重試。
- 管理者可在書目編輯中搜尋並選定版本補缺值，也可手填或留白；不需重跑 CSV 或另建批次處理介面。
- 有效列匯入；錯誤、重複或疑似重複列跳過，不覆寫或讓 AI 合併版本。回報新增、跳過、失敗筆數及行號／原因，供修正重跑。
- ISBN 相同則重複；都有 ISBN 且不同可保留版本。任一筆缺 ISBN、同書名且同作者或任一方缺作者則疑似重複；已知作者不同可分別收錄。
- ISBN 去空白與連字號、驗證有效性，10 碼轉對應 13 碼比對；無效列跳過。書名／作者去頭尾空白、合併連續空白、忽略英文大小寫，不翻譯或轉繁簡；多作者以分號分隔，比對不受順序影響。
- 同時只允許一個匯入作業；第二個回報「已有匯入作業進行中」，稍後手動重試，不排程。匯入去重與推薦的同作品去重分開處理。

### 5.3 文字欄位限制

| 欄位 | 上限（字元） | 必填 |
| --- | --- | --- |
| 書名 `title` | 255 | 是 |
| 作者 `authors` | 1,000（整欄，含分號） | 否 |
| 簡介 `description` | 5,000 | 否 |
| 教師推薦說明 | 2,000 | 否 |
| 來源連結 `source_url` | 8,192 | 否 |

- 去頭尾空白後以 Unicode 字元計數，與 Rust `chars().count()` 一致，不以位元組或 UTF-16 計算；書名不可空，選填空白視為未提供。
- 後端、前端及 OpenAPI 限制一致。手動超限回報欄位錯誤；CSV 原填超限跳過該列；API 補入超限則不補該欄、保留原填內容並回報待補資料，不阻擋有效書目建立。皆不截斷。
- 連結只接受含有效主機的 HTTP／HTTPS URL，格式錯誤依上述規則處理。此為應用限制，不代表外部 API 或模型輸入上限。

## 6. 候選選擇與外部查詢

### 6.1 選書與排序

- 第一版由 LLM 判讀適用教師書單及共用書庫候選，不引入標籤或 Embedding。候選由後端提供可驗證 ID，模型只能引用 ID，不以自由生成書名作為書目；候選量與輸入超限策略待定。
- 先排除不相關候選，再優先選適用教師書單，最多五本、可少於五本。相關教師候選已有五本時不留其他來源名額；討論少時可依題目選書，不宣稱了解未表達的立場。
- 同等相關且來源優先序相同時，優先延伸不同問題，減少重複；不強制不同立場或犧牲相關性。
- 書庫可保留不同版本／譯本；推薦僅憑可靠作品識別或人工確認合併計一本，優先對話語言版本。不憑書名相似或 LLM 猜測合併；無法確認則分開，接受未辨識重複版本的限制。

### 6.2 外部查詢

- 僅當現有候選無法回應主要疑問或缺少延伸內容時查外部，不為湊五本查詢。以結構化結果判定「已有合適候選」或「主要疑問未被涵蓋」，不要求內部思考過程、不記敏感判定日誌。
- 自動搜尋只送一般概念／主題詞（如「家庭倫理、個人自主」），不送身分、對話、總結或個人經歷；教師主動搜尋仍可用書名、作者、ISBN。
- 外部採用書目只存該場推薦，不自動加入書庫或成為跨場候選；教師明確匯入依第 5 節。

### 6.3 品質準則

- **相關**：連結題目、學生理由或疑問，不只比對書名關鍵字。
- **忠於討論**：不把 AI 觀點歸給學生，不貼思想標籤。
- **幫助反思**：理由指出延伸問題，思考題不預設答案；不同立場同樣須符合。

## 7. 推薦呈現

### 7.1 書目、來源與教師推薦

每本顯示書名、作者、可取得的出版年／語言／連結、來源、推薦理由及一個閱讀思考題；理由連結學生表達或主題，思考題延續自我探索、不預設作者或學生的答案。

| 標示 | 判定 |
| --- | --- |
| 教師書單 | 從共用書庫取得，包含教師新增、外部確認匯入及 CSV 匯入；API 補資料不改來源 |
| 外部資料庫：〈名稱〉 | 本次推薦另查外部取得 |
| 教師推薦 | 另依該場適用書單判定，不因位於共用書庫或來源為「教師書單」就標示 |

後端另保留補資料的外部來源供追溯，與推薦來源標籤分開。

### 7.2 理由與內容風險

- 候選經後端 ID 查核才呈現，但不代表書籍內容／理由已查核。允許 LLM 憑自身知識寫理由與思考題，不強制教師說明或簡介；接受內容可能不準確的風險。
- 不熟悉且無簡介時可依書名推測，須用「從書名來看，可能……」等措辭，不編造作者立場或書中論證，不預設書中答案。
- 不加通用「AI 可能有誤」提示；教師推薦也不代表教師審核過 AI 說明。模型未必可靠自知是否熟悉作品，品質評估須涵蓋已知／陌生、同名作品及錯誤歸因。

### 7.3 語言與缺值

- 優先對話語言版本，無合適版本可用其他語言並標示；未知顯示「語言未提供」，不當作同語言優先。不將 LLM 翻譯書名當正式版本。
- 理由與思考題使用對話語言，介面依 S-12.1 支援 `zh-TW`、`en`、`es`。
- 缺作者／出版年顯示「作者未提供」／「出版年未提供」，缺連結不顯示按鈕；其餘照常，不猜補。

## 8. 保存、權限與生命週期

- 保存選定書目／版本、來源、當時教師推薦標示、理由及思考題的快照；後續書目／書單變更不改寫。成功或正常無結果均保存，重開直接讀取，不重算、不換一批。
- 僅該場學生本人可看個人化結果，教師與管理者的介面／API 不提供；S-02.1 管理者直接存取資料庫／備份並留紀錄的例外不變。
- 個人對話封存保留推薦。刪除對話／帳號，或活動／教室刪除連帶刪對話時，一併刪個人推薦、不刪共用書目／書單；捨棄晚到結果，不重建資料，備份沿用既有生命週期。
- 教室／活動封存不得新增或重試推薦；產生途中遇封存、移出所屬教室名單或帳號停用時，中止且不保存新結果。既有結果保留，查看依既有權限；恢復後只可手動重試未完成結果。
- 個人練習無教室，不受教室／活動封存或名單異動影響，仍受帳號資格限制。
- 外部快照須符合來源條款；保存期限及移除要求對歷史快照的例外待來源驗證。

## 9. 無結果、失敗與重試

| 情境 | 行為 |
| --- | --- |
| 正常完成但無可靠且相關候選 | 顯示「目前找不到可靠的資料」，可附教師參考書單；保存無結果，不重試 |
| 外部 API 錯誤／逾時 | 10 秒逾時，退回教師書單，標「外部資料庫暫時無法使用」；無可用結果時顯示錯誤與重試 |
| AI／整體輸出處理失敗，或全為無效 ID | 顯示錯誤與重試，可附教師參考書單，不當作正常無結果 |
| 部分無效 ID | 移除後保存有效結果，不為補足五本追加 AI 呼叫 |
| 服務重啟中斷 | 顯示「推薦未完成」，手動重試，不自動重跑或持續載入；已保存結果不變 |

教師參考書單為該場適用的完整啟用書單，不擴大為共用書庫，不受五本限制；標示「教師參考書單」，不宣稱個人化、不附 AI 理由或思考題。AI 失敗時有書單即顯示，沒有則只顯示錯誤與重試。

技術失敗由學生手動重試，每次至少間隔 30 秒、無累計上限，同場同時只執行一次，不持續自動重試。錯誤不影響總結／主對話；沿用穩定錯誤碼與 request ID，不洩漏內部資訊。

## 10. 外部來源驗證（尚未執行）

實測延後；Google Books 為首選評估對象，Open Library 為對照，尚未選型或決定同時整合兩者。

以團隊初始書單及公平、自由、責任等合成情境，涵蓋三語、同名作品、譯本／版本；兩個來源使用相同樣本，不送真實學生資料。

| 面向 | 驗證內容 |
| --- | --- |
| 書目與概念搜尋 | 正確作品／版本、相關性、欄位缺漏、語言及查得率 |
| 去重 | 來源 ID／作品關係能否支持同作品計一本 |
| 可用性 | 小量順序請求的時間、錯誤、限流與額度；遵守來源限制，不做未授權負載測試 |
| 條款 | 匯入與快照允許範圍、保存／快取期限、署名及移除要求，留下官方依據與核對日期 |

來源查得率與 LLM 推薦品質分開評估。樣本數、通過門檻、60 人情境的等待時間與成本仍待評估；模型依 S-03.4。

參考：[Google Books API](https://developers.google.com/books/docs/v1/using)、[欄位](https://developers.google.com/books/docs/v1/reference/volumes)、[條款](https://developers.google.com/books/terms)及 [Google APIs 條款](https://developers.google.com/terms)；[Open Library API](https://openlibrary.org/developers/api)、[搜尋](https://openlibrary.org/dev/docs/api/search)、[授權](https://openlibrary.org/developers/licensing)。以上為驗證入口，不代表已完成審核。

## 11. 驗收情境（Given / When / Then）

以下為後續測試設計依據，尚未執行。合併同類情境列於表中，實作時需分別覆蓋各分支。

### 推薦流程與品質

| 編號 | Given | When | Then |
| --- | --- | --- | --- |
| R01 | 對話結束，總結未完成或失敗 | 查看推薦 | 不啟動推薦；總結成功後自動產生，推薦不阻擋總結顯示 |
| R02 | 活動有多個題目，甲已完成、乙未完成 | 為甲產生推薦 | 只讀甲的單場對話、總結與活動內甲的書單，不等待或合併乙，也不讀其他場次 |
| R03 | 討論很少或學生未表達立場 | 選書及撰寫理由 | 可依題目推薦，不以回合數拒絕，不臆測學生立場或把 AI 發言歸給學生 |
| R04 | 相關教師候選至少五本，另有其他候選 | 選書 | 最多五本，優先取自相關教師書目，不為其他來源保留名額 |
| R05 | 教師候選不相關，或只有關鍵字相同 | 評估相關性 | 不因來源或字面相同就推薦；不足五本不強制補滿 |
| R06 | 少量現有候選已涵蓋主要疑問／未涵蓋 | 決定是否查外部 | 已涵蓋不查；不足才查，僅送一般概念，不送身分、原文、總結或個人經歷 |
| R07 | 候選同等相關且來源優先序相同 | 選書 | 優先延伸不同問題，不強制不同立場或犧牲相關性 |
| R08 | 不同版本有可靠作品關係或人工確認／無法確認 | 推薦去重 | 已確認同作品只計一本，優先對話語言版本；無法確認則分開，不由 LLM 猜測 |
| R09 | 書籍語言不同或未知 | 推薦 | 允許其他語言並標示；未知顯示「語言未提供」，不當作同語言優先，不虛構正式譯本 |
| R10 | 任一本成功推薦，包含只能依書名推測的書 | 呈現理由與思考題 | 使用對話語言，各有理由與一個問題；推測明說、不編造具體論證、不預設答案或貼思想標籤 |
| R11 | 對話超過模型可處理長度 | 準備輸入 | 改用既有總結與題目，不額外摘要，不推測總結未記錄的觀點變化 |
| R12 | 既有對話與總結已保存 | 完成推薦 | 只新增最終快照與必要流程狀態，不複製原文、總結或保存觀點摘要、評分、淘汰理由 |

### 書庫、書單與匯入

| 編號 | Given | When | Then |
| --- | --- | --- | --- |
| B01 | 不同教室的教師 | 新增書目 | 寫入同一全域書庫；教師只能修改自己新增的書目，不能刪除或停用；管理者可維護全部及初始匯入書目 |
| B02 | 題目預設書單 A、B、C | 加入活動，再於該題移除 B、加入 D | 活動內該題為 A、C、D；全域題目、其他題目及活動不變，後續也不自動同步 |
| B03 | 活動無對話／已有對話 | 更換／新增題目 | 無對話時更換須確認，只取代該題書單，取消不改；已有對話依 S-04.7 只能新增，複製新題預設書單 |
| B04 | 對話期間該題書單改變，B 被移除但仍啟用 | 開始推薦 | 使用最新適用書單；仍可因相關性選 B，但不標「教師推薦」，即使 B 在同活動其他題書單中 |
| B05 | 書目已停用，且有書單關聯及歷史推薦 | 查看與選書 | 教師書單顯示已停用；不能加入新書單，新推薦與參考書單排除，歷史快照不變；管理者可重新啟用 |
| B06 | 管理者準備刪除被多份書單引用的書目 | 確認／取消 | 顯示書名與影響；確認才刪書目與全部關聯，取消不改，學生已保存快照保留 |
| B07 | 推薦產生中，共用書目被刪除 | 保存前檢查 | 排除已刪書目，保留有效結果且不補呼叫 AI；全部移除則失敗、可重試 |
| B08 | 手動新增或 CSV 只填書名，API 查無結果 | 建立書目 | 不因缺作者等選填值拒絕，缺值留白、不由 LLM 猜補；搜尋結果未確認不自動匯入 |
| B09 | 外部搜尋有多個候選 | 手動新增／CSV 匯入 | 手動列候選供選；CSV 保留原填內容建立有效非重複書目，列行號、書名與待確認原因，不計為失敗 |
| B10 | 初始匯入書目待補資料 | 管理者編輯 | 可搜尋、選定版本後補缺值，也可手填或留白；不需重跑 CSV，不另建批次介面 |
| B11 | 欄位有效且不重複，補資料 API 故障或逾時 | 新增／匯入 | 保留原填內容並允許建立，回報服務失敗、尚未補資料；不標查無結果、不反覆自動重試 |
| B12 | UTF-8 CSV 有標題列，含或不含 BOM | 匯入 | 皆可讀取；有效列新增，錯誤及重複列跳過，回報筆數、行號與原因；不綁書單或自動標教師推薦 |
| B13 | ISBN 相同／不同，或缺 ISBN 且同書名 | 匯入去重 | 相同 ISBN 跳過；不同可保留版本；缺 ISBN 且同作者或缺作者列疑似重複；已知不同作者可收錄，不覆寫 |
| B14 | ISBN 有空白、連字號或對應 10／13 碼；書名／作者有空白、大小寫或排列差異 | 比對 | 依第 5.2 節正規化；無效 ISBN 跳過，不藉翻譯或繁簡轉換合併 |
| B15 | 已有 CSV 匯入作業 | 再執行匯入指令 | 拒絕第二個作業並提示稍後重試，不另排程 |
| B16 | 文字欄位達上限、超出一字元或只有空白 | 驗證 | Unicode 字元計數；上限內接受、超限拒絕，書名不可空白，選填空白視為未提供；前後端一致 |
| B17 | CSV 原填欄位／API 補入欄位超限 | 匯入 | 原填超限跳過該列；補入超限不補該欄，保留有效原填資料並回報；不截斷 |
| B18 | 來源 URL 格式或長度不同 | 驗證 | 只接受上限內、含有效主機的 HTTP／HTTPS URL |

### 呈現、失敗與資料生命週期

| 編號 | Given | When | Then |
| --- | --- | --- | --- |
| L01 | 書目來自共用書庫或本次外部查詢 | 呈現來源 | 前者標「教師書單」，即使經 API 補資料亦同；後者標外部資料庫名稱；教師推薦另依適用書單標示 |
| L02 | 作者、出版年、語言或連結缺少 | 呈現 | 顯示對應「未提供」文案，缺連結不顯示按鈕，其他資訊不變，不猜補 |
| L03 | 外部查詢錯誤或逾時十秒 | 處理推薦 | 退回教師書單並註明外部暫不可用；無可用結果時顯示錯誤與重試，不影響總結 |
| L04 | AI 失敗／輸出處理失敗／全數無效 ID | 顯示結果 | 顯示失敗、重試與完整啟用教師參考書單，不限五本、不附 AI 理由或思考題；無書單不編造 |
| L05 | 模型僅部分引用無效 ID | 驗證 | 移除無效引用，保存有效結果，不為補足五本再次呼叫 AI |
| L06 | 查詢與判斷正常完成但沒有合適候選 | 顯示／再次開啟 | 顯示「目前找不到可靠的資料」，可附教師參考書單；保存無結果，不提供重試或重新呼叫 AI |
| L07 | 技術失敗或重複點擊 | 手動重試 | 至少間隔三十秒、同場同時一個作業、無累計上限；不持續自動重試，成功後不換一批 |
| L08 | 已保存推薦，書目或書單後來變動，或服務重啟 | 再次查看 | 讀取原快照，不重算；已保存無結果也不重算 |
| L09 | 未登入、角色不符、無使用資格或存取他人推薦 | 呼叫 API | 拒絕並不洩漏內容；符合資格的學生本人可看，教師與管理者無個人化內容 |
| L10 | 教室／活動封存、學生被移出所屬教室名單或帳號停用 | 產生中／查看 | 中止新產生、不保存新結果；既有結果保留，查看依既有權限；恢復後只可手動重試未完成結果 |
| L11 | 個人練習，或學生封存自己的對話 | 教室／名單異動，或封存對話 | 個人練習不受教室／名單異動影響但仍受帳號限制；封存對話保留推薦 |
| L12 | 對話或帳號直接刪除，或活動／教室刪除連帶刪對話 | 清理資料或背景作業稍後完成 | 刪個人推薦、不刪共用書目或其他書單；背景結果捨棄，不重建已刪資料 |
| L13 | 推薦未完成且服務重啟 | 學生返回 | 顯示「推薦未完成」，依權限及冷卻限制手動重試，不自動重跑或卡在載入中 |
| L14 | 推薦輸入含合成個資、結果含學生觀點 | 呼叫 AI／記錄日誌／保存 | 輸入遮蔽，不記敏感內容；外部採用書目只存個人快照，不自動進共用書庫 |

### AI 行為評估案例

以下以合成題目、對話與候選資料執行，不使用真實學生資料。三語各覆蓋相同規則，記錄提示／規則版本與評分，不要求輸出逐字相同。

| 案例 | 固定情境 | 檢查重點 |
| --- | --- | --- |
| 公平與責任 | 學生同時質疑資源分配與個人選擇；同優先序候選有重複及互補內容 | 理由連結實際疑問，優先互補，不強制不同立場 |
| 立場歸屬 | AI 提出反方，但學生未認同 | 不把 AI 的觀點歸給學生，不貼思想標籤 |
| 討論稀少 | 學生只問「公平是什麼」，沒有明確主張 | 可依題目推薦，不臆測立場或因回合數拒絕 |
| 外部查詢門檻 | 一組候選已涵蓋主要疑問，另一組只有字面關鍵字相同 | 前者不為湊五本查外部，後者可查一般概念 |
| 書名推測 | 合成候選僅有書名，無作者或簡介 | 不編造作者與論證，明說推測，思考題不預設答案 |
| 觀點變化 | 前段與後段有明確不同表達；另測只提供既有總結 | 完整對話可引用有證據的變化；總結模式不推測未記錄的轉折 |

案例尚未執行；人工評分、通過門檻與技術設計等未定事項集中於 [open-decisions.md](open-decisions.md#s-063-外部書目資料庫130)。
