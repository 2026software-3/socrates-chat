# S-04 個性傾向雷達圖

本文件記錄 S-04.2 與 S-04.3 的驗收情境；規則以 [`decisions.md`](decisions.md) 為準。

- Given 題目已產生六個維度，When 不同學生討論同一題，Then 他們使用同一組維度與評分準則。
- Given 學生在 AI 追問後實際表達或修正想法，When 評分，Then 該內容與必要上下文納入判斷。
- Given 某維度沒有足夠證據判斷，When 六個分數產生，Then 該維度為 0 分；它是完整結果的一部分，平均時算 0 分。
- Given 固定測試情境，When 對同一份對話重複評分，Then 每個維度所得分數的差距最多 1 分。
- Given 題目已有對話且六個維度已完成，When 教師修改維度，Then 只能修改名稱及說明措辭，不能更換維度或修改評分準則。
- Given 總結成功，When 六維計分成功，Then 保存完整雷達圖；計分失敗或缺少分數時保留總結，學生可手動重試。
- Given 題目維度產生失敗，When 學生開始並完成對話，Then 題目仍可使用且保留總結；維度完成後學生可手動觸發補算。
- Given 班級或主張群平均，When 教師查看，Then 包含截至查看時的完整結果、不包含已刪除對話，顯示小數點後兩位；少於三人不特別標示。
