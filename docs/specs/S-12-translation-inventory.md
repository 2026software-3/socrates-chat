# S-12 翻譯流程盤點

本表整理各規格的翻譯對象與已確認方向；完整規則以各規格及 [`decisions.md`](decisions.md) 為準。

| 內容 | 來源與處理 | 規格 |
| --- | --- | --- |
| 動態內容 | 優先瀏覽器 `Translator` API，其次後端 Google Cloud Translation API，最後後端 AI；後端背景工作沒有可用瀏覽器時從 Google 開始 | S-12.1 |
| 學生對話總結 | 產生時準備並儲存原文與三語版本；失敗顯示原文、標示待完成並自動重試；既有總結背景補譯。翻譯僅傳送立場與理由，不傳對話原文或學生身分 | S-12.1 |
| 題目雷達圖維度 | AI 根據題目產生維度；名稱與說明依翻譯順序準備三語。教師可檢視修正各語言，儲存修改不重新觸發翻譯 | S-04.2、S-04.6 |
| 自訂成就名稱與說明 | 管理者輸入一種語言，另兩語依翻譯順序產生；首批文案隨 seed 提供 | S-07.3 |
| 部件名稱 | 預定支援三語；品項與素材等仍待決定 | S-07.1 |
| 按鈕、提示、通知、錯誤訊息與點數名稱 | 原規格使用三語資源檔；是否改為動態翻譯待確認 | S-12.1、S-07.2 |
| 題目文字、教師書單 | 多語版本或單語加語言標示仍待確認 | S-12.1 |
| 書名、作者及書目比對 | 正規化與比對不使用翻譯；不得把機器翻譯書名當成正式出版版本 | S-06.3 |
| 固定遮蔽與個資佔位詞 | `message`、`[EMAIL]`、`[PHONE]`、`[NATIONAL_ID]`、`[STUDENT_ID]` 不翻譯 | S-02.1、S-02.6 |

瀏覽器翻譯能力依瀏覽器與語言配對而異；必須能在不可用時繼續備援。三語為 `zh-TW`、`en`、`es`。AI 以對話語言直接產生回覆及總結，不應將生成與翻譯混為一談。
