# 已結束對話的匯出與匯入（S-02.5）

> 2026-11 需求方確認部分決定（#452）；檔案格式、驗證與錯誤處理等仍待確認，尚未實作。

## 已確認

- 匯出與匯入僅供測試使用，測試環境才可啟用；正式環境隱藏按鈕，後端也拒絕匯入與匯出請求。

- 學生可匯出自己的已結束對話作為備份；進行中的對話不能匯出。可在清單中選擇多場匯出，也可一次匯出全部已結束的對話。
- 備份使用系統專用的 JSON 檔，可用一般文字編輯器讀取，包含格式版本、題目、完整對話訊息、AI 總結與分析結果；遇到不支援的格式版本時拒絕匯入並顯示提示。
- 學生可一次匯入包含多場對話的備份檔；備份也可以交給另一位學生匯入。每場匯入的對話建立一份新副本，不覆蓋既有對話。
- 批量備份檔中若有對話格式錯誤，匯入格式正確的對話，並列出失敗的項目。
- 同一帳號重複匯入同一場對話時預設跳過，結果列為「已匯入」；不同學生可各自匯入同一場對話。第一版不提供允許重複匯入的選項。
- 匯入的副本顯示備份當時保存的題目內容，不受原題目後續修改或刪除影響。
- 匯入的副本屬於匯入者的個人練習，維持已結束狀態，並附註「匯入的對話」。原為活動對話的副本不計入活動完成狀態，也不改變原活動的完成狀態。
- 匯入的總結與分析結果隨副本顯示，並納入匯入者的個人統計、整體雷達圖與學習成就計算。匯入不重新發放對話點數；若匯入後達到新的成就門檻，解鎖並發放該成就。
- 管理者及教師的既有資料可見與遮蔽規則仍適用（S-02.1、S-02.2、S-14）。

## 仍待確認

- 測試功能的具體啟用與環境判定方式；具體格式版本、大小限制、資料驗證、損壞檔案之處理。
- 同一場對話的辨識方式；匯入內容的來源與完整性如何呈現。
- 匯入或匯出其他角色資料的具體權限，以及資料保存與刪除細節。
