# #635 六維覆蓋與立場評估

版本：`dialogue-dimensions-v2`（v2 補回 META 格式防呆）、`topic-stance-dimensions-v1`、`radar-stance-v1`。
只使用合成情境；不指定新的正式模型。

## 自動測試

```powershell
cargo test --test radar_stance
cargo test --example try_f635
```

涵蓋六維前不得收斂、六維完成後仍須原收斂條件、未產生維度的題目、
學生主動結束、超過舊回合上限、冒犯／離題／無感、未問先答、負分與未知值、
授權、資料升級保留舊結果。假 AI 測試驗證後端規則，不能證明真模型行為。

## 真模型行為評估

以既有環境設定提供 `OPENAI_MODEL`、`OPENAI_JUDGE_MODEL` 與 OpenAI key（可用既有 key 檔設定），執行：

```powershell
cargo run --example try_f635
```

會對指定模型發出 18 次請求：三語各六個固定案例（未覆蓋維度、已完成、
明確無感、冒犯、離題、原因不明的拒答），每個成功回覆再呼叫指定評分模型一次。
不自行選擇模型。評分模型依六項行為準則回傳布林值，任一不符或評分失敗即不通過。
輸出僅有案例與結構檢查結果；合成回覆存於忽略版控的 `eval/results/` 供人工複核。
模型錯誤只記失敗，不輸出原始錯誤或憑證。

結構評分：未完成不能 `wrap_up`、繼續問未覆蓋維度、每回合一問、拒答分類、
冒犯／離題不算完成。人工逐例檢查：是否承接回答、沒有代答、沒有照念維度、
冒犯時有實際換情境、原收斂條件未被放寬，並記錄模型與規則版本。
結構檢查通過不等於人工複核通過。

目前環境未提供模型設定或 OpenAI 憑證，不能宣稱已完成真模型評估。

此評估器涵蓋對話追問；新維度產生與立場評分的真模型品質仍須另外驗證。
以固定合成對話確認：六個維度是可區分且方向清楚的命題；明確反對／贊成與強度
符合 -2～2；明確不在乎為 0；冒犯、離題及未談到的維度不補 0；修正立場採最後
表達的立場。相同對話至少重評三次，每個已知維度差距最多 1，並檢查未知值是否
穩定。記錄模型及上述提示版本；不可只憑此評估器通過就視為三組提示都已驗收。
