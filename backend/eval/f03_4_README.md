# F-03.4 題目維度評估

固定情境見 `f03_4_cases.json`，三題皆為合成資料，涵蓋繁體中文、英文與西班牙文。生成與 AI 備援翻譯提示版本為 `topic-dimensions-v1`，人工評審準則版本為 `f03.4-review-v1`。

- **區辨性**：任兩維度描述的判斷或行為可區分。若同一句理由總是同時支持兩個維度，檢查它們是否同義。
- **情境涵蓋**：六維涵蓋情境中主要的取捨。以情境檔的 `coverage` 提示作為評審參考，允許同義或更貼切的觀點。
- **可計分**：每個維度的 1 到 5 分各有可觀察的定義，強度逐級增加。0 分一律表示證據不足。
- **三語對應**：逐一比對同一維度的名稱與白話說明，確認譯文仍表達原意、未更動順序且各語言表達自然。

從 `backend/` 執行：

```bash
cargo test --example try_f034
cargo run --example try_f034
```

第一個指令只跑離線格式及版本檢查。第二個指令使用已設定的 `OPENAI_MODEL` 與 OpenAI 金鑰，輸出各情境的 JSON 紀錄至標準輸出，包含提示版本、模型、解析結果與 AI 備援譯文。人工依上述準則記錄通過或需修正的理由。

本次以合成回應驗證六維、五級準則、三語對應、失敗重試和編輯鎖定。此環境未設定模型及金鑰，真實模型品質與人工複核尚無結果。
